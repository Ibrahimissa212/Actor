# Images

Put your photos here, then reference them in `content/photos.ts`.

Guidelines:

- Compress before adding. Keep each file under ~300 KB.
- Resize to about 1600 px on the long edge (plenty for web).
- Use the exact file names you reference in `content/photos.ts`
  (e.g. `headshot-1.jpg`, `class-1.jpg`).

Free tools to compress: https://squoosh.app or https://tinypng.com
